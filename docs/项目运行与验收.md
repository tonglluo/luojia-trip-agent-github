# 项目运行与验收

## 一、验收目标

本交付包需要同时满足：

1. 在新的 Python 虚拟环境中可安装并运行 CLI。
2. 不包含真实 API Key 和个人记忆。
3. 六类业务 Skill、RAG 文档、本地模型和缓存完整。
4. 离线核心回归测试通过。
5. 三套正式评测集、人工复核结果和最终报告可追溯。
6. 对外指标与冻结报告一致，不使用旧版估算指标。

## 二、最小运行流程

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
# 编辑 .env，填入自己的 ZHIPUAI_API_KEY
.\.venv\Scripts\python.exe cli.py health
.\.venv\Scripts\python.exe cli.py
```

`health` 失败时，CLI 不应继续错误路由，而应提示模型服务暂时不可用。

## 五、重新运行正式评测

正式评测会调用外部模型、耗时较长并产生费用。只有在模型、Thinking、数据集和评测协议固定时，才能与冻结结果比较。

意图识别：

```powershell
.\.venv\Scripts\python.exe evaluation\run_intent_eval_repeated.py
```

RAG 检索：

```powershell
.\.venv\Scripts\python.exe evaluation\run_rag_eval.py `
  --dataset evaluation\datasets\rag_eval.formal.v1.jsonl
```

串并行配对延迟：

```powershell
.\.venv\Scripts\python.exe evaluation\run_paired_latency_benchmark.py
```

不要覆盖冻结报告。新实验应使用新的输出文件和版本号。

## 六、已知限制

- 正式评测使用单一模型供应商账号和单台工作站，绝对延迟会受网络与配额影响。
- RAG Recall@5 为100%只表示每道可回答题至少命中一个期望来源，不代表所有来源均完整召回。
- 并行执行提高了 Agent 阶段速度，但增加了 429 重试压力。
- 实体字段准确率90.86%刚过门槛，是后续最需要监控的质量项。
- 最终 HTML 报告完成结构验证；冻结时本机没有 Chromium，因此未执行浏览器窄屏和来源弹窗交互检查。
